## Combat-complete parts

These are the only parts that exist on **all nine** combat pages — the safe set for a
character creator in a game where the player can draw a weapon:

- **0bas-body** — `humn` (human)
- **1out-outfit** — `boxr` (boxers), `fstr` (forester tunic), `pfpn` (peasant farmer pants), `undi` (undies)
- **4har-hair** — `bob1` (bob), `dap1` (dapper)
- **5hat-hat** — `pfht` (peasant hat), `pnty` (pointed hat)

Everything else is movement-only. Parts on `p1`–`p4` but not the combat pages will
simply have no sheet to draw while a weapon is out.
